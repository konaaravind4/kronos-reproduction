Method
Two-Stage Architecture

Kronos abstracts financial K-line sequences as a discrete language via a two-phase framework: tokenization and autoregressive pre-training.

Stage 1
K-line Tokenizer
📊 Input: OHLCVA
Open · High · Low · Close · Volume · Amount (D=6)
shape (T, 6)
🧠 Transformer Encoder
Contextual representation of each K-line item
⚡ BSQ Quantizer
Binary Spherical Quantization — k=20 bits total
coarse: k/2=10 bits fine: k/2=10 bits vocab: 2^10=1024
🔄 Transformer Decoder
Hierarchical reconstruction loss (coarse + fine)
Stage 2
Autoregressive Pre-training
🎯 Token Sequence
b₁, b₂, …, bT where bₜ = [bᶜₜ, bᶠₜ]
🤖 Decoder-only Transformer
Causal attention + RoPE embeddings. 3 model sizes: 4.1M → 499M params
next-token prediction
📐 Hierarchical Prediction
Predict coarse subtoken → cross-attn → predict fine subtoken
🎲 Inference (Monte Carlo)
Temperature scaling + top-p sampling + N-path ensemble
test-time scaling

Insights
Key Findings
🏆
+93%
RankIC over Best TSFM
General-purpose TSFMs (TimeGPT, TimeMoE, Chronos) significantly underperform on financial data. Domain-specific pre-training matters.
⚡
N×
Test-Time Scaling Works
Ensembling more Monte Carlo trajectories monotonically improves IC and RankIC — compute can be traded for accuracy at inference time without retraining.
🔤
BSQ
Discrete > Continuous
Discrete token modeling (via Binary Spherical Quantization) outperforms continuous-space regression and probabilistic models on financial time series.
📈
Scaling
More Params = Better
Performance consistently improves from Kronos-mini (4.1M) to Kronos-large (499M), following LLM-style scaling laws for financial time series.
🎭
+22%
Better Synthetic Data
Kronos-generated synthetic K-lines better mimic real market distributions — lower discriminative score and higher TSTR usefulness than all generative baselines.
🌍
Zero-shot
Generalizes Across Assets
Kronos excels in a zero-shot setting across crypto, equities, forex, and commodities from 45 exchanges — without any task-specific fine-tuning.
💡

The Core Insight

Financial K-line data is a language. By treating each OHLCVA bar as a discrete "word" and pre-training an autoregressive LM on this language across global markets, Kronos learns rich, transferable representations of market dynamics — the same way GPT learns from text.
